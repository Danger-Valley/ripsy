  gating and checkout behavior remain unchanged. Android also gains the ambient
  jumps that were already in iOS 71 but absent from APK 70. Web Shop remains static.

  all eight figure digest/geometry/timeline/input contracts and both-platform
  release preflight pass. Health/Redis/configured push, live shop catalog and
  public Privy native configuration are checked read-only. Configured push is
  not a delivery test. No payment, wallet approval or on-chain operation occurred.

  purchasable models on iPhone Simulator and Seeker/BONK on iPad Simulator, using
  the actual shared showcase/current JS in an existing binary. Remote-only Rives
  were locally staged in that isolated fixture. This is not a new real-device,
  production cache/auth/purchase or installation test during release packaging.
  See `WEB_PARITY_HANDOFF.md` for the complete evidence limits.
- Build subprocesses inherit only an allowlist of standard runtime variables
  and public native Privy identifiers, never private root `.env` backend values.
  Package scans below compare configured local private-value representations in
  memory only; these bounded checks are not a comprehensive security/secret audit

- No manual backend/web deployment, env/key/authority/catalog/pack-policy/
