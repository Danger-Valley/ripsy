# RIPSY 1.0.0 (57)

Release date: 2026-10-08. Source baseline: `69b4856` plus synchronized native build number 57.

## Included changes

- ORE fighter support in shop, collection, army and gameplay. Current pack edition 2 remains Jup 40%, BONK 40%, ORE 20%, priced at 1,099 SKR. No program or probability changes in this release.
- Backend-delivered figure definitions and verified private Rive downloads allow future compatible figures without another native release. Free/bundled figures still work offline; ownership and one-asset-per-slot checks remain authoritative.
- Mandatory mobile update screen controlled by backend minimum build numbers and separate store links. Production policy was read-only verified with minimums disabled; this release does not force anyone to update.
- Android adaptive launcher icons fill the launcher's mask instead of appearing as a small square in a white compatibility plate. Original artwork, iOS/web icons and Android splash raster references remain unchanged.

## Verification

- All 501 mobile tests (48 suites), mobile TypeScript, five-model Rive contract/digest checks and both-platform production release preflight pass.
- Production `/shop/figures`, version-4 catalog and `/mobile/update-policy` return successfully. No backend deployment or configuration mutation was performed during this release.
- Both production JavaScript bundles were checked against five configured private server environment values, including RPC, session, mint-authority and Firebase service-account material. No matches; values were not logged or exported to native build tools.
- All five packaged Rive files match checked-in assets byte for byte on both platforms. Archived native app contains the RipsyAppInfo and RipsyFigureCache bridges.
- No Expo, Simulator, paid transaction or physical-device install/test was performed. Physical Seeker launcher appearance, device animation/thermal behavior and paid purchase/VRF validation remain pending.
