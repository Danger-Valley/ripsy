# RIPSY Android 1.0.0 (64)

Built and published on 2026-10-12 from source `4acaa63`. Android only - no
TestFlight build or upload was requested in this release. The shared native
build counter is now 64.

## Included changes since Android 63

- Failed and expired figure purchases offer a guarded Retry. The old order is
  checked before creating a fresh purchase, preserving quantity and SOL funding.
- The shop shows a visible preparation state on entry. Token shortfalls use a
  yellow warning so Buy with SOL remains the main action.
- Army Remove uses the coral button tone.
- Opponent previews recover the correct front-facing Rive state after a cold
  model load instead of showing an occasional back-facing fighter.

The Seeker pack signing issue remains unresolved. A previous wallet approval
was rejected by the backend before broadcast, apparently because the wallet
returned a different transaction message. This release does not change pack
transaction verification or claim a successful paid pack test.
