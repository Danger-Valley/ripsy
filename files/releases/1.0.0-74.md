standing public Download publication. Source `2075ad1` plus native build counters

release 73; the Firebase persistence cutover is backend-only and already works
through the existing client API. Bare React Native Community CLI, locked

Fresh 818 mobile tests / 59 suites with open-handle detection, mobile TypeScript,
eight-model PNG/Rive digest/geometry/timing/input contracts and both-platform
release preflight pass. Public backend health 200 reports Firestore ready, Redis
connected and push configured; v4 retains seven products and original prices.
No real wallet/payment, onchain, physical-device/offline or push-delivery test
was performed. Existing security/dependency work remains separate; this is not
an App Store production-readiness or security-audit signoff.

Build children inherit an allowlist of runtime variables and the two public
Privy native IDs, never the root backend secrets. APK/archive/exact distribution
IPA pass a bounded 23-unique-pattern representation scan from ignored local env
and the dedicated Firebase commerce private key, with zero matches and all five
canonical bundled Rives present. This is not a scan of every Railway value or
every secret that has ever existed. No Firebase, wallet, authority, treasury,
pack policy, price, update-minimum or backend configuration changed.
