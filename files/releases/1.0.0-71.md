independent Shop ambient jumps for TestFlight only. iOS Debug/Release build

## Scope and checks

- Visible native Shop models use their authored Front/No Weapon idle and
  occasional Jump Forward, independently timed with an ID-derived phase and
  fresh 3–7 second jittered delays. Focus, viewport, foreground, popups and Reduce
  Motion gates cancel the controller/timer. No changes to checkout, gameplay,
  Army/pack portraits, prices or Rive asset files. Web Shop remains static.
- Fresh 796 mobile tests/56 suites with open-handle detection, native TypeScript,
  all eight model digest/geometry/timeline/input contracts and iOS release
  preflight pass. Backend/Redis health, configured push, live catalog and public
  Privy native configuration are checked read-only; configured push is not a
  delivery test. No purchase or on-chain signing/broadcast was performed.
- Build subprocesses receive an allowlist of ordinary runtime variables and
  public native Privy identifiers, not private root `.env` values. All 189 archive
  app files pass a bounded check for 19 local configured private-value
  representations (zero matches) and all five bundled Rive digests match.
  This is not a comprehensive secret/security audit or a Railway-variable scan.
- No dependency update, manual backend/web deployment, production env/key/
  authority/catalog/update-minimum change, Android release, external beta review
  or App Store production submission is part of this task. The old Railway
  automation remains paused. Existing dependency-advisory reachability work is
  still open.
- Physical-device, real wallet/payment, push delivery and unobstructed visual
  jump/landing checks remain unverified. The preceding implementation's iOS
  Simulator attempt was blocked by a system dialog; packaging does not close
  that validation gap or imply production-store approval.
