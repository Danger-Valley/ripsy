# RIPSY Android 1.0.0 (63)

Built and published on 2026-10-12 from implementation
`b629d6eb3e66b9d0f54e395497bc24517d34b3a5`, with the normal production
entry point. Source build counters advanced to 63 on both platforms; no iOS
binary was built or uploaded.

## Included changes since Android 62

- Figure quantity picker, 1..3 per purchase, with exact total price, one atomic
  payment and a distinct buyer-owned asset per figure. Restored single orders
  remain compatible. SOL recovery preserves the count and request; oversized
  exchange routes are rejected before approval rather than split into payments.
- Installed version/build/platform/channel headers on configured first-party
  API requests and native WebSocket handshakes. Backend treats them as advisory,
  not authentication or Seeker attestation.
- Existing mandatory-update screen now defaults to You have to update the app;
  Seeker opens the native dApp Store package link with configured HTTPS fallback.
  Production minimums remain 0. Do not activate until the listing/install route
  is verified on a physical Seeker.

Packs remain single-pack purchases. Pack price/odds/VRF, paid receipts and
onchain programs were not changed. The previously reported wallet-message
rejection for a pack is a separate unresolved diagnosis, not a fix in this APK.
