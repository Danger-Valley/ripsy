# RIPSY 1.0.0 (58)

Release date: 2026-10-10. Source baseline: `efe50c6` plus synchronized build number 58 and release-preflight correction.

## Included changes

- Android proportional illustrated startup splash.
- Saved completed purchases no longer automatically reopen their popup on Shop entry; explicit View purchase and unfinished recovery remain available.
- Disconnected Seeker purchase entry points connect the wallet directly, without the email/account chooser. Connection does not automatically prepare or sign a purchase.
- Seeker fighter uses the backend-provided SKR payment; current default is 1 SKR. SOL shortfall recovery for figures and packs offers explicit Buy with SOL, review and wallet approval with atomic exchange/payment.
- Pack price/storage upgrade is already active independently on mainnet. This native release changes no prices, odds, pause flags, editions or authorities. Current pack remains edition 2, 1,099 SKR, Jup/BONK/ORE 40/40/20.
