# RIPSY 1.0.0 (56)

Release date: 2026-10-07.

## Included changes

- Figure and pack purchase preparation, review, signing, processing, recovery and reward now use the native purchase popup. Closing it hides the popup without cancelling a signed or paid order.
- A subtle static tint marks the last opponent move destination without changing selection, legal targets or Rive timing.
- Trap presentation keeps the completed collision instance mounted and starts a fresh instance only for the next collision. Removed the extra implicit activation that could replay the trap.
- A late `The game is not active` rejection no longer covers a confirmed finished result. Authoritative finish immediately disables stale move and weapon-picker actions; unrelated errors remain visible.
- Existing pack prices, probabilities, purchase eligibility and signer validation are unchanged.
