# RIPSY 1.0.0 (69)

Release date: 2026-10-28. Source baseline: `7ff68c9` with native build numbers synchronized to 69. This release delivers the previously committed idle shop previews, anonymous-session/401 recovery and official native Seeker Connect 0.2.0 migration. No new product behavior or dependency updates were introduced by this build task; the existing bare React Native Community CLI projects remain Expo-free.

## Scope and verification

- User requested Android and TestFlight builds. The standing Android instruction includes publication to the existing `Danger-Valley/ripsy-downloads` / `seeker-latest` Download channel. No Google Play, Solana dApp Store, external beta-review or App Store production submission was performed.
- All 758 mobile tests across 56 suites pass with open-handle detection; native TypeScript, all eight model digest/geometry/animation contracts and both-platform release preflight pass. Backend/Redis health, push configuration, the live shop catalog and native Privy public configuration were checked read-only. Health's push configuration flag does not prove push delivery.
- Build subprocesses inherited only an allowlist of standard runtime variables and the public Privy app/client identifiers, not private backend values from `.env`. The iOS archive and each non-directory APK/IPA ZIP entry were scanned for 19 exact configured private-value representations from the local environment; no matches were found. This is a bounded exact-value check, not a comprehensive secret audit or a fresh check of every Railway variable.
- All five bundled Rive content digests match canonical sources in the APK, archive and IPA. The three additional remote figures are not newly bundled or published by this task.
- No backend/web/catalog/update-policy deployment, environment/key/authority change, wallet connection, real purchase, payment or physical-device validation was performed. The existing order-recovery limitation after loss of an anonymous player ID remains documented; this build does not add wallet-signed order rebinding. Web Seeker Connect, browser cached-token repair UI and web idle previews remain unported.
- Dependency advisory reachability/targeted-update work remains separate and open. Build success is not a full security signoff or production-store approval. The Railway monitoring automation remains paused.
