## Included behavior and proof limits

Delivers the Duo adaptation: actual provider-pane sizing, independent safe-area
edges, measured parent board geometry, stable carousel/selection/form state,
iOS27.1+ UIKit overlay arrangement and modal-local active division geometry.
An empty preferred modal region after keyboard avoidance uses the opposite
nonempty continuous region, without recreating the form. Older iOS retains the
original host; minimum iOS17 is unchanged. Android receives the shared responsive
JS and ordinary full-area dialog fallback, not an iOS-only native component.

Pre-release source QA on Duo/iOS27.2 actually verified selected open/active-half
Home/Army/Shop, baseline local-lineup continuity, collection/settings dialogs and
retained email input with a visible keyboard across both fold axes. The two
native modal failures were reproduced and fixed. That local Simulator artifact
used counter74, not the signed distribution IPA75. Closed hinge/AX state passes,
but both closed displays returned black screenshots; no closed visual PASS or
physical-device/all-pose/paid-wallet/push-delivery certification is implied.
See `iphone-duo-preparation-2026-11-04.md` for exact evidence and remaining cases,
including a positive-but-unusably-thin preferred pane. No Apple/Google production
store submission or security-audit signoff is implied by beta delivery.

## Verification

Fresh830 mobile tests/60suites with open-handle detection and default timeout,
mobile TypeScript, eight canonical PNG/Rive byte/geometry/timing/input contracts
and both-platform release preflight PASS. Preflight includes compiling the actual
native modal geometry helper with13 cases, iOS audio/Firebase guards, SDK27.1+
and Android optimization/signing prerequisites. Existing third-party Gradle/
R8/Google Play Services and native deprecated-keyWindow warnings were not hidden
or patched during this release.

Build children inherit only normal runtime variables and two public native Privy
IDs, never root backend secrets. Explicit Xcode build settings supply those IDs;
both final APK DEX and IPA Info.plist exactly match the expected public native
configuration. APK, archive app and exact exported IPA pass a bounded23-pattern
representation scan from ignored local env and the known dedicated commerce
private key, with zero matches and all five bundled Rives verified. This is not
a scan of every current Railway value or every historical secret.

No backend/catalog, Redis/Firestore/Storage data, credentials/authority, treasury,
pack policy, prices, update minimum or web product code was changed. Firebase
migration was not rerun. Existing GitHub version/docs autodeploy may run; no manual
duplicate deployment is part of this request. Dependency-advisory reachability
and physical-device work remain separate open gates.
