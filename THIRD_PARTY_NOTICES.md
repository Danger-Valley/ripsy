# Third-party design references

## Free Game UI Kit

- Creator: [Tahorin Binta Jaman](https://www.figma.com/@tahorin)
- Source: [Free Game UI Kit](https://www.figma.com/community/file/1065913909118984412/free-game-ui-kit)
- License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

RIPSY's mobile interface adapts the kit's general component language: violet playfields, light floating panels, rounded arcade controls, colored menu tiles, ribbons, and tactile bottom-edge depth. RIPSY retains its own artwork, game content, palette roles, copy, and interaction flows.
