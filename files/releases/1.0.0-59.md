# RIPSY 1.0.0 (59)

Release date: 2026-10-12. Source baseline: `779de07` plus synchronized native build number 59.

## Included changes

- Figure/pack Buy and Buy with SOL proceed directly to the selected wallet signer, without an additional native quote-confirmation popup. Persisted intents, final status checks, one operation lock and already-signed byte reuse preserve recovery and duplicate-payment protection. Restore/poll never starts signing automatically.
- Android/Seeker illustrated splash aspect-fits the full root viewport. Safe-area/loading reservations no longer shrink the art; logo/loading overlay it. Original artwork, iOS cover, Android system icon splash and startup timing are unchanged.
- Removed numeric FIG badges from native shop artwork; backend-provided fighter names and Seeker exclusivity labels remain. Prices, catalog definitions, purchase eligibility, pack odds and onchain rules are not changed by this release.
